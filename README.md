# 바퀴길

휠체어·유모차·자전거 이용자를 위한 "가장 편한 길" 추천 서비스입니다. 노면의 진동·턱·경사 측정값을 간선 비용으로 바꾸고, 직접 구현한 최소 힙과 다익스트라 알고리즘으로 이동수단별 최적 경로를 찾습니다.

빌드 도구 없는 정적 사이트(HTML/CSS/JavaScript)이며, `main`에 push하면 Vercel에 자동 배포됩니다.

## 데이터 교체

- `data/graph.json`: 장소(정점)와 길(간선). 지금은 가상의 예시이며, 실제 데이터에서는 `"example": true`를 지웁니다.
- `data/measurements.json`: 구간별 측정값. 지금은 가상의 예시입니다.
- 이동수단별 가중치: `js/graph.js`의 `VEHICLES`

측정값은 `/measure.html`(데이터 제작용 측정 도구)에서 내보낸 JSON 파일을 그대로 쓸 수 있습니다.
